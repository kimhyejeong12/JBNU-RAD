# 보안 솔루션 정책 운영 기준

## 5. 정책 작성 원칙

### 5.1 명시적 거부 우선
방화벽 정책은 명시적 거부(DENY)를 우선 적용한다.
동일 대상에 ALLOW 와 DENY 가 함께 존재하면 DENY 가 우선한다.

### 5.2 광범위 허용 금지
출발지 또는 목적지에 ANY 를 사용하는 ALLOW 정책은 금지한다.
불가피한 경우 책임자 승인과 함께 만료일을 반드시 지정한다.

### 5.3 정책 중복 관리
동일한 출발지·목적지·포트 조합에 대한 정책이 둘 이상 존재하면 중복으로 본다.
중복 정책은 통합하고 사용하지 않는 정책은 폐기한다.

## 6. 솔루션 간 정합성

### 6.1 DLP 와 SWG
SWG 에서 파일 업로드를 허용하더라도 DLP 의 외부 유출 차단 정책이
우선 적용되어야 한다. 두 정책이 상충하면 DLP 를 기준으로 조정한다.

### 6.2 PAM 계정
PAM 으로 관리되는 특권 계정은 개인 계정과 분리하여 운영한다.
특권 계정의 직접 로그인은 금지하며 반드시 PAM 을 경유한다.

### 6.3 정책 만료 관리
모든 예외 허용 정책은 만료일을 지정하고, 만료 7일 전에 담당자에게 통보한다.
만료된 정책은 자동으로 비활성화한다.
